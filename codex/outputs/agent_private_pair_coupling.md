# Actual pair completion, exchange classes, and the endpoint minimum

Status: the lemmas and the six-row construction below are hand proved.
The construction uses the established FKW parity family's property (7,2)
as an input, without rerunning its certificate. It attains the global
minimum endpoint cardinality p=t, on the globally minimum number of
vertices. It is **not** asserted to attain the secondary minimum of the
number of piercing pairs, or to be saturated. These qualifications are
the remaining global-potential issue, not suppressed hypotheses.

The general asymptotic 3/4 upper bound is not proved here.

## 1. A complete trace block generated by one common outside defense

Let H be an actual rank-at-most-k family, let tau(H)=t, and let T be a
global minimum transversal. For y outside T put

    S_y = {x in T : every E in H with E intersect T={x} contains y}.

The quantifier ranges over the full actual private-edge family, not a
selected representative. Write S=S_y, s=|S|, K=T\S, and C=S union {y}.
Assume s>0 and define the actual residual subfamily

    L = {E in H : E intersect K=empty}.

**Lemma 1 (complete pair block and exchange symmetry).**

1. tau(L)=s, every edge of L meets C in at least two points, and every
   two-subset of C is the exact C-trace of an actual edge of L.
2. For every x in S the set T_x=(T\{x}) union {y} is a global minimum
   transversal. Relative to T_x, the full private-family defense set of
   the outside point x is exactly

       S_x^(T_x) = (S\{x}) union {y}.

**Proof.** The set T_x meets every edge: an edge missed by T\{x} is
private to x relative to T and therefore contains y. Its size is t.

The set S covers L. If L had a cover of size less than s, adjoining K
would cover H with fewer than t points. Thus tau(L)=s. For each a in C,
C\{a} covers L: for a=y this is S, and for a=x in S it follows from
the global cover T_x after removing K. An edge meeting C in only a
single point a would miss C\{a}, which is impossible. If a pair R in
C were not an exact trace, then C\R, of size s-1, would cover L:
any edge missing it would have its C-trace contained in R, hence equal
to R by the lower bound of two. This contradicts tau(L)=s.

For the symmetry claim, a T_x-private edge of y has old T-trace exactly
{x}, and hence contains x. For z in S\{x}, a T_x-private edge of z
avoids y and has old T-trace contained in {x,z}. Its trace cannot be
{z}, by the defining property z in S, so it contains x. Conversely,
if z is in T\S, some old T-private edge of z avoids y. It remains
T_x-private to z and avoids x. These three cases prove the equality.
QED.

Thus pair completion gives a genuine exchange class of minimum covers.
It does not directly decrease their size or decrease the six-tuple
potential. If H has (7,2), L has (7,2) because L is an actual subfamily;
no such assertion is made about its two-point trace projection.

## 2. A valid way to consume a succession of common defenses

The same argument has a higher-trace form which makes precise what a
successful iteration would need.

**Lemma 2 (trace threshold and common-defense peeling).** Suppose L is
an actual family with tau(L)=s, and C is a set of size s+r-1 such that
every edge E of L satisfies |E intersect C|>=r. Then:

* every s-subset of C covers L;
* every r-subset of C is the exact C-trace of an actual edge of L;
* if z outside C belongs to every actual edge whose C-trace has size r,
  then C'=C union {z} satisfies the same hypotheses with r+1 in place
  of r.

**Proof.** An s-subset of C has complement of size r-1, so it must meet
every edge. For an r-subset R of C, the set C\R has size s-1 and fails
to cover L. An actual edge missing it has C-trace contained in R, and
therefore equal to R. Finally an edge with C-trace at least r+1 already
has that many points in C'; an edge with C-trace exactly r contains z
by hypothesis. Also |C'|=s+(r+1)-1. QED.

Starting from Lemma 1 gives r=2. Each step requires a common outside
point of the **entire** family of actual minimum-trace rows. It is not
enough to find a common point of one selected representative for each
trace.

If this procedure reaches r=k in a rank-at-most-k family, all k-subsets
of the resulting (s+k-1)-set are actual edges. Property (7,2) then gives

    s <= 7 ceil(k/4)-k = 3k/4+O(1).

Indeed, a complete k-uniform family on at least 7 ceil(k/4) vertices
contains seven bad rows: use seven equal classes of size ceil(k/4),
take the four classes off each Fano line, and shrink each resulting
set to k points. Any two points are missed by one of the seven rows.

This is a conditional route, not an assertion that peeling reaches k.
A two-point outside cover of the minimum-trace rows is materially
different from a common point: adding both points raises the trace
threshold by only one, while increasing the block size by two. The
identity |C|=s+r-1 is then lost and the exact trace-completion argument
does not continue at the same transversal number.

## 3. An actual parity benchmark with p=t and S_y=P

Fix an odd integer m>=11, put k=4m and t=3m+1, and let V have size
7m+1. Choose A_* subset V of size 4m and set B_*=V\A_*. Let

    H = {E subset V : |E|=4m and |E intersect A_*| is odd}.

The established FKW parity-family result gives property (7,2) in this
range. The following additional statements are proved directly here.

Every (4m+1)-set contains an actual edge: it has a point in both A_*
and B_*, so deleting one of these two differently colored points gives
the required parity. Consequently tau(H)>=3m+1. A (3m+1)-set whose
A_*-intersection has even size has an even-parity 4m-set as complement,
and hence is a cover. Therefore tau(H)=t.

The vertex count is globally minimum for rank 4m, property (7,2), and
transversal number at least t. On at most 7m vertices, pad with isolated
points to 7m and partition into seven m-sets indexed by Fano points. If
every union of three classes on a Fano line failed to cover, choose an
actual edge missing each such union. The resulting seven actual rows
would have no piercing pair. Thus one of the seven 3m-sets is a cover.

### 3.1 Six actual rows attaining the first global potential

Partition V into C_1,C_2,C_3,C_4,Z_1,Z_2,Z_3, with

    |C_i|=m,  |Z_1|=|Z_2|=m,  |Z_3|=m+1.

Start with six containing rows whose membership types are

    C_1: 135       C_2: 146       C_3: 236       C_4: 245
    Z_1: 3456      Z_2: 1256      Z_3: 1234.

Thus a point of C_1, for example, lies in rows 1,3,5. Rows 1,2,3,4
have size 4m+1 and rows 5,6 have size 4m. Put

    P=Z_1 union Z_2 union Z_3.

The piercing-pair graph of these containing rows is exactly the complete
tripartite graph on Z_1,Z_2,Z_3. Distinct Z-types have union [6], whereas
identical Z-types do not. Any C-type omits one coordinate from each
of {1,2},{3,4},{5,6}; it therefore cannot supplement the missing pair
of any Z-type. Finally no two C-types have union [6].

Choose a in C_1, choose an (m-2)-subset R_2 of C_2, and specify

    A_* = P union {a} union R_2.

This has size 4m. Both 1 and m-2 are odd. The contribution from P is
odd in rows 1,2,3,4 and even in rows 5,6; the parity contribution from
{a} union R_2 is odd precisely in rows 3,4,5,6. Consequently the
containing rows have odd total A_*-parity in rows 1,2,5,6 and even
parity in rows 3,4.

Choose c in C_1\{a}, d in C_3, and b in R_2. Make the following four
deletions, one from each oversized row:

    row 1: delete c;   row 2: delete d;
    row 3: delete a;   row 4: delete b.

Rows 5,6 are unchanged. All six resulting rows F_1,...,F_6 have size
4m and odd A_*-parity, so they are actual edges of H. Deleting
incidences cannot create piercing pairs. Since none of the Z-incidences
was deleted, all old complete tripartite pairs survive. Hence the exact
endpoint set is still P and

    |P|=3m+1=t,    |Pi|=m^2+2m(m+1)=3m^2+2m.

For any six actual rows of a (7,2) family, their endpoint set is a global
transversal: an actual edge avoiding all endpoints would, together with
the six rows, violate (7,2). This also holds when the six rows already
have a common point. Thus every such endpoint set has size at least t,
and the displayed six-tuple attains the global minimum of |P|.

It has **not** been proved that 3m^2+2m is the minimum value of |Pi|
among six-tuples with |P|=t. The construction establishes the first
potential exactly and leaves the second as an explicit open condition.

### 3.2 Full private families and their forced pair rows

Write O=V\P and R_*=A_*\P. Then

    |O|=4m,    |R_*|=m-1,    P subset A_*.

An actual singleton-P-trace row must have the form

    {x} union (O\{v}),       x in P, v in O.

Its A_*-intersection has size m-1_{v in A_*}. Since m is odd, the row
is actual precisely when v is in B_*. In particular, the **entire**
private family of every x in P contains every point of R_*. Thus

    S_y=P for every y in R_*.

For any distinct x,x' in P, any y in R_*, and any v in B_*, the row

    {x,x'} union (O\{y,v})

is actual, has exact P-trace {x,x'}, and avoids y. Its A_*-intersection
has size m, which is odd. For a fixed y, all these pair rows still
contain R_*\{y}, of size m-2. Hence a maximal S_y and actual complete
pair completion can coexist with another large common outside defense,
even when P is the endpoint set of a globally endpoint-minimizing
six-tuple and the whole family is globally vertex-minimum.

### 3.3 Peeling stops at a genuine two-point defense

Add h distinct points of R_* to P, where 0<=h<=m-1, and call the
result C_h. It has size 3m+1+h and lies in A_*. Every actual edge
has C_h-trace at least h+1. Indeed it has trace at least h by cardinality;
equality would force it to contain all 4m-h outside points and give
total A_*-intersection m-1, which is even.

An edge with trace exactly h+1 contains all but one point outside C_h.
Its parity is odd precisely when that omitted point is in B_*. Thus
the entire minimum-trace family contains all remaining points of
R_*\C_h. Lemma 2 can therefore peel these common defenses successively.

At h=m-1 it reaches C_h=A_* and trace threshold r=m=k/4. The exact
minimum-trace family is

    {L union (B_*\{v}) : L in binom(A_*,m), v in B_*}.

Its common intersection outside A_* is empty. Nevertheless any two
points of B_* meet every row of this family, because each row omits
only one B_*-point. The peeling hypothesis fails at r=k/4, even though
the common-defender iteration has successfully run for linearly many
steps in an actual (7,2) family with a globally minimum endpoint set.

## 4. What the benchmark does and does not obstruct

The first endpoint potential, full singleton-family quantifiers, actual
pair completion, and globally minimum vertex count together do not
force |S_y| to be small, eliminate common outside defenses in one step,
or make common-defense peeling reach rank k. The benchmark satisfies
all those hypotheses and has |S_y|=t.

It does not contradict a 3/4 asymptotic upper bound: its excess is only

    t-3k/4=1.

It also does not settle the jointly minimizing six-tuple case, since
the secondary pair minimum was not established, and saturation was
not imposed. A valid next target must use at least one of these missing
conditions, or a quantitative positive excess above 3k/4, to rule out
the terminal two-point defense. Merely counting forced pair traces or
changing between the minimum covers in Lemma 1 cannot do that by itself.

In particular, an argument using the six-tuple must show how an actual
row supplied by trace completion yields a replacement with either
fewer endpoints, or equal endpoint count and fewer piercing pairs.
No such two-row replacement inequality is proved here.

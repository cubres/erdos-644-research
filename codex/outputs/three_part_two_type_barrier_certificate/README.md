# Three-part obstruction to two-type proofs

Proposition 7.79 in the research note gives nine types with continuous coefficient 483/640 > 3/4 while every subfamily of at most two types has property (7,2). The whole family has an explicit bad seven-tuple, so this is a method obstruction, not a counterexample to Erdős Problem 644.

Run `python3 -B -S p644_three_part_two_type_barrier_check.py`. This checks all 3,402 pair exclusions, two exhaustive transversal calculations and two positive witnesses. Completeness of the 42-function criterion is the separately replayable dependency `../two_type_capacity_certificate/`; this small bundle does not replace that proof.

Nothing has been published. General Problem 644 remains unresolved in this work.
